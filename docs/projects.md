## Reviewing a project

Start with the live site when one exists. Then read the corresponding repository README for setup, implementation notes, screenshots, and limitations. Client projects are labeled as client work because source access may not be public. The absence of a public repository is not an invitation to infer ownership or implementation details beyond what the portfolio states.
